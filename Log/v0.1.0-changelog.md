# Mon3ter v0.1.0 更新日志

> 2026-06-30 | 基于 v0.0 (commit `2d98d90`) 的增量变更

---

## 一、功能添加

### 1.1 人格系统完整实现

| 文件 | 行数 | 说明 |
|------|------|------|
| `mon3ter/personality/character.py` | 185 | 人格引擎：加载 character.yaml，组装三层身份 System Prompt |
| `mon3ter/personality/emotion_state.py` | 217 | 情绪状态机：LLM标签 > 关键词匹配 > 空闲衰减，6 种情绪 |
| `mon3ter/personality/character.yaml` | 100 | 角色卡：核心身份 + 价值观 + 性格 + 说话规则 + 情绪触发 |
| `mon3ter/personality/__init__.py` | 12 | 模块导出 |

**亮点**：三层身份模型（我是谁 → 我信什么 → 我怎样说话）。System Prompt 由 8 个片段动态拼装，与模型无关——只产文本，不调推理。

### 1.2 推理进程隔离

| 文件 | 行数 | 说明 |
|------|------|------|
| `mon3ter/core/inference_worker.py` | 157 | 子进程入口：独立加载 Llama，通过 Queue 通信 |
| `mon3ter/core/engine.py` | +253 | `InferenceWorkerClient`：与 InferenceEngine 共享相同 API |

**架构**：主进程 ←→ `multiprocessing.Queue` ←→ Worker 子进程（独占 Llama 实例）

**收益**：
- 模型崩溃 ≠ 服务崩溃（worker 自动重启）
- 为模型热切换打下基础
- 显存隔离，推理互不干扰
- `config.yaml` → `models.load.use_worker: true` 开启

### 1.3 Clock 统一时间抽象

| 文件 | 行数 | 说明 |
|------|------|------|
| `mon3ter/core/clock.py` | 86 | 新增：`RealClock`(Asia/Shanghai) + `FrozenClock`(测试用) |

所有 `datetime.now()` 调用收敛到 `mon3ter.core.clock.now()` / `now_iso()`，显式时区，可注入假时钟测试 recency 衰减。

### 1.4 回退模式增强

当 `conversation/` 模块未就绪时，回退模式不再是裸引擎对话：

- **System Prompt 注入**：自动从 personality 引擎构建角色卡 prompt
- **对话历史管理**：单连接内维护 `ConversationContext`，记住上下文
- **日志准确化**：启动日志显示"有 System Prompt"而非"无记忆/人格"

## 二、结构优化

### 2.1 server.py 移入 mon3ter/ 包

- `server.py` 从根目录迁至 `mon3ter/server.py`
- `main.py` 导入从裸 `import server` 改为 `from mon3ter import server`
- 消除跨层裸 import，所有代码在 `mon3ter/` 包内

### 2.2 ConversationContext 轮索引管理

`_trim()` 从"搜索 user/assistant 配对删除"改为`_rounds: list[(user, assistant)]` 轮索引：
- O(1) `pop(0)`，不受 system/tool 消息干扰
- `history` 变为 property，展平时自动按轮输出

### 2.3 requirements.txt 精简

- 从 105 行（含全部传递依赖如 kubernetes、googleapis 等）精简到 29 行
- 只保留 5 个直接依赖，传递依赖由 pip 自动解析
- 未来模块依赖以注释形式预留

### 2.4 Engine 锁范围文档化

`chat_stream()` 添加完整注释说明锁覆盖整个生成周期的原因（llama-cpp-python 内部状态不支持并发 completion），并标注 TODO(2.1) 进程隔离后锁可降级。

### 2.5 配置与入口

- `config.yaml` 新增 `models.load.use_worker: false`
- `mon3ter/__init__.py` 新增模块导出
- `ModelLoadConfig` / `ModelLoadSection` 新增 `use_worker` 字段
